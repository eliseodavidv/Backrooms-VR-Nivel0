# Backrooms VR · Nivel 0

Experiencia de terror en realidad virtual para Meta Quest 2, inspirada en los Backrooms.
El jugador despierta en un laberinto de pasillos idénticos y debe encontrar la salida en 8 minutos sin que una entidad lo atrape.

Curso CS2H01 Interacción Humano-Computador, UTEC.
Equipo: Alejandro Vargas Rios, Eliseo David Velásquez Díaz, Paolo Centeno.
Profesor: Teófilo Chambilla.

## Tecnología
- Unity 2022.3.62f3 (render Built-in)
- Meta XR SDK (Interaction SDK)
- Plataforma: Meta Quest 2 (Android)

## Qué incluye (Entrega 3, 50 %)
- Movimiento por teletransporte con arco, giro por pasos de 45° y viñeta de comodidad
- Laberinto de 15x15 celdas con una entidad que patrulla, sospecha, persigue y busca
- Escondites, sonido espacial y alertas visuales y hápticas
- Combate: barra de metal y pistola que se agarran con controles, manos o a distancia; 5 mini monstruos (3 de vida); 3 vidas del jugador
- Menú, tutorial, pausa con volumen, reloj en la muñeca y fin de partida
- Modelos reales de la Unity Asset Store optimizados para Quest 2

## Cómo abrirlo
1. Clonar el repositorio.
2. Abrir la carpeta con Unity 2022.3.62f3 (módulo Android instalado).
3. Abrir la escena `Assets/Backrooms_Main.unity`.
4. Para el visor: File > Build Settings > Android > Build And Run.

Nota: algunas carpetas de modelos de otra escena (`Planta-Andahuasi` y `Texturas-adicionales`) no se subieron por su tamaño y no se usan en el juego.

## Créditos de modelos (Unity Asset Store)
